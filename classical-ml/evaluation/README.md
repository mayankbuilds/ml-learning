# Model Evaluation

Model evaluation estimates how well a machine learning model generalizes to unseen data and supports reliable comparison between candidate models.

## Learning Objectives

- Understand training, validation, and test sets.
- Apply cross-validation correctly.
- Evaluate classification models using appropriate metrics.
- Evaluate regression models using error metrics.
- Compare models using consistent experimental conditions.

## Topics

1. [Train, Validation, and Test Sets](train-test-validation.md)
2. [Cross-Validation](cross-validation.md)
3. [Classification Evaluation](classification-evaluation.md)
4. [Regression Evaluation](regression-evaluation.md)
5. [Model Comparison](model-comparison.md)

## Recommended Order

1. Understand data splitting and generalization.
2. Learn cross-validation.
3. Select appropriate classification and regression metrics.
4. Compare candidate models fairly.
5. Keep the test set for final evaluation.

## Key Reminder

A strong evaluation estimates performance on unseen data. Avoid leakage, use consistent splits when comparing models, and choose metrics based on the actual problem.
