# Clustering

Clustering is an unsupervised machine learning task that groups similar data points without requiring predefined target labels.

## Learning Objectives

- Understand unsupervised learning and clustering.
- Implement K-Means clustering.
- Understand DBSCAN and noise detection.
- Evaluate clusters using inertia and silhouette score.
- Visualize and interpret clustering results.

## Topics

1. [K-Means](k-means.md)
2. [DBSCAN](dbscan.md)
3. [Clustering Evaluation](clustering-evaluation.md)

## Prerequisites

- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Feature scaling and distance metrics

## Recommended Order

1. Learn K-Means and visualize its clusters.
2. Study DBSCAN and compare its behavior with K-Means.
3. Evaluate clustering results and understand their limitations.

## Key Reminder

Clustering results depend on the dataset, feature scales, distance metric, and algorithm parameters. A cluster label is a group identifier, not a meaningful class name by itself.
