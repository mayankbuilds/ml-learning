# Regression

Regression is a supervised machine learning task used to predict continuous numerical values.

## Topics

| File | Coverage |
|---|---|
| `linear-regression.md` | Linear model, coefficients, assumptions, implementation |
| `regression-metrics.md` | MAE, MSE, RMSE, and R² |
| `regularization.md` | Overfitting control using Ridge and Lasso |

## Learning Objectives

- Fit and interpret a Linear Regression model.
- Understand coefficients, intercepts, predictions, and residuals.
- Evaluate regression models using appropriate metrics.
- Recognize the assumptions and limitations of ordinary least squares.
- Understand how Ridge and Lasso regularization affect model fitting.

## Recommended Order

1. Linear Regression
2. Regression Metrics
3. Regularization

## Dependencies

- NumPy
- Pandas
- Matplotlib
- scikit-learn

Run the examples using the Python environment configured for this repository.
