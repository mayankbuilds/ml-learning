# Classification

Classification is a supervised machine learning task in which a model predicts a discrete class label.

## Topics

| File | Coverage |
|---|---|
| `logistic-regression.md` | Sigmoid, probabilities, decision thresholds |
| `decision-trees.md` | Splitting criteria, tree depth, overfitting |
| `random-forest.md` | Ensemble learning, bagging, feature importance |
| `knn.md` | Distance-based classification, scaling, choosing k |
| `svm.md` | Margins, support vectors, kernels |
| `classification-metrics.md` | Confusion matrix, precision, recall, F1, ROC-AUC |

## Learning Objectives

- Understand binary and multiclass classification.
- Train and compare common classification algorithms.
- Interpret predicted probabilities and decision thresholds.
- Evaluate models using metrics appropriate to the problem.
- Recognize class imbalance, overfitting, and data leakage.
- Understand when feature scaling is important.

## Recommended Order

1. Logistic Regression
2. Classification Metrics
3. Decision Trees
4. Random Forest
5. k-Nearest Neighbors (kNN)
6. Support Vector Machines (SVM)

## Dependencies

- NumPy
- scikit-learn
- Matplotlib (for optional visualizations)

Examples use generated datasets so they can be reproduced without downloading external data.
