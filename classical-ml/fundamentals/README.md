# Classical ML Fundamentals

Core concepts required to understand, train, evaluate, and improve classical machine learning models.

## Topics

| File | Coverage |
|---|---|
| `ml-workflow.md` | Features, targets, training, prediction, and the ML workflow |
| `overfitting-underfitting.md` | Generalization, overfitting, underfitting, and bias–variance intuition |
| `baseline-models.md` | Baseline predictions and simple reference models |

## Learning Objectives

- Understand the structure of a supervised learning problem.
- Follow a reliable machine learning workflow.
- Distinguish training performance from generalization performance.
- Establish a baseline before comparing more complex models.
- Recognize common sources of evaluation errors.

## Recommended Order

1. ML Workflow
2. Overfitting and Underfitting
3. Baseline Models

These fundamentals apply to both regression and classification tasks.
